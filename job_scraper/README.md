# 招聘岗位要求抓取器

按 **招聘平台 / 岗位 / 年限 / 薪资 / 公司规模 / 工作地点** 抓取 JD，自动拆成“一条要求一行”，
导出带格式的 Excel。目前接入猎聘，平台层已抽象，可继续扩展。

## 快速开始

需要工作区自带的 Python（已含 openpyxl）：

```powershell
$py = "C:\Users\wdb\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe"
cd tools\job_scraper

# 方式一：命令行
& $py cli.py -k "SAP MM" -y 3-5 -s 15-30 -c 1000+ -l "上海,北京,深圳" -n 100

# 方式二：一问一答
& $py cli.py -i

# 方式三：网页界面（推荐给非技术用户）
& $py web.py            # 浏览器打开 http://127.0.0.1:8765
```

输出默认在 `tools/job_scraper/output/招聘要求_平台_岗位_地点_时间.xlsx`，可用 `-o` 指定路径。

## 参数说明

| 参数 | 说明 | 示例 |
|---|---|---|
| `-p/--platform` | 招聘平台 | `liepin`（默认） |
| `-k/--keyword` | 岗位关键词，同时作为搜索词 | `"SAP MM"`、`"Java开发"` |
| `-y/--years` | 经验年限 | `3-5`、`3+`、`1-3`、`不限` |
| `-s/--salary` | 月薪范围（千元） | `15-30`、`20+`、`1.5万-2.5万`、`不限` |
| `-c/--people` | 公司规模（人数） | `1000+`、`500-2000`、`100+`、`不限` |
| `-l/--location` | 工作地点，逗号分隔；省名会展开为省内城市 | `上海`、`广东`、`上海,北京` |
| `-n/--rows` | 最多导出多少行（一个岗位一行） | `100` |
| `--max-per-company` | 同一公司最多几行 | `3`（默认）、`0`=不限 |
| `--require` | 岗位名称必须具备的词（逗号分隔） | `SAP,MM` |
| `--exclude` | 排除词（命中岗位名称即丢弃） | `实习,外包,销售` |
| `--years-mode` | `overlap`=年限区间有交集（默认）；`contains`=岗位年限完全落在输入区间 | `overlap` |
| `--max-details` | 最多抓多少条详情（控制耗时） | `150` |
| `--no-cache` | 不使用详情缓存 | — |
| `-o/--output` | 输出 Excel 路径 | `D:\out\mm.xlsx` |

`-h` 查看全部参数，`--list-platforms` 查看可用平台。

## 筛选逻辑

1. **岗位相关性**：关键词检索 + 岗位名称必备词过滤（如 `SAP,MM`），可选排除词。
2. **工作地点**：地点串匹配（`上海` 命中 `上海-浦东新区`）；省名自动展开为省内城市；
   默认排除境外与港澳台（`--include-overseas` 可关）。
3. **经验年限**：把 `3-5年`、`3年以上`、`经验不限`、`5-10年` 解析为区间后比较。
4. **薪资**：把 `15-30k·13薪`、`20-40万/年`、`8000-12000元/月` 统一折算成 **千元/月** 再比较。
5. **公司规模**：把 `1000-2000人`、`10000人以上` 解析为人数区间比较。
6. **详情二次校验**：抓完详情后用详情页的公司/地点/年限再校验一次，减少卡片信息误差。
7. **行数控制**：一个岗位一行；同一公司默认最多 3 行；总行数不超过 `--rows`。

> 默认 `overlap` 模式下，标注“5-10年”的岗位也会命中“3-5年”（因为区间有交集）。
> 只要严格 3-5 年，用 `--years-mode contains`。

## 输出 Excel（4 个工作表）

- **岗位需求明细**：一个岗位一行，A–M 共 13 列——序号、公司名称、岗位名称、工作地点、公司规模、经验要求、学历要求、薪资范围、
  **需求内容（猎聘“职位介绍”栏全文，保留原始换行）**、命中关键词、职位链接、平台、抓取时间。
  已按要求去掉原 I/J 列（要求类型、细分类型）。
- **公司与岗位汇总**：每个岗位一行，另附“拆分要求条数”（由职位介绍拆出的条目数，仅供参考）。
- **筛选条件与统计**：本次输入的条件、每公司上限、各阶段数量统计、错误提示。
- **职位清单**：命中的岗位及其原始链接，便于核对。

## 技术要点

- 猎聘搜索接口 `com.liepin.searchfront4c.pc-search-job` 需要 `X-XSRF-TOKEN`（先访问站点拿 Cookie）
  和 `X-Fscp-*` 请求头；实测 PC UA 会拿到空响应 `{"flag":0}`，用 **移动端 UA** 正常。
- 详情页用移动页 `https://m.liepin.com/job/<id>.shtml`，正文在 `<script type="application/ld+json">`
  的 `JobPosting` 里；`/a/<id>.shtml` 与 `/job/<id>.shtml` 两种链接都做了兼容。
- 服务端每页固定 42 条、最多 10 页，单关键词最多约 420 条，所以程序会去重合并多个关键词结果。
- 详情默认缓存到 `data/detail_cache.json`，按 `平台:jobId` 存储，重复运行不再请求。

## 新增招聘平台

1. 在 `platforms/` 下新建 `xxx.py`，实现 `Platform` 的三个方法：
   `iter_cards()`（翻页产出卡片）、`to_posting()`（卡片 → JobPosting）、`fill_detail()`（抓正文）。
2. 用 `@register` 装饰类，设置 `name`（如 `"51job"`）和 `label`。
3. 在 `platforms/base.py` 的 `_load_builtin()` 中导入该模块。
4. `cli.py` / `web.py` 的平台下拉框会自动出现新平台。

## 注意事项

- 仅供个人求职分析与学习使用；请遵守目标网站的服务条款与 robots 规则，控制请求频率。
- 招聘网站的接口/页面结构可能变化，若报“搜索接口返回异常”，通常是风控或结构变更，可稍后重试或更新适配器。
- 部分企业被平台匿名化展示（如“某上市生物医药营销公司”），程序保留平台原始名称。
